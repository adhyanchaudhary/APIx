An Airfare Price Index for India's busiest metro air routes

Problem & Solution

Airfares are volatile and opaque. Travelers can't tell good from bad prices, and India has no official number tracking how the cost of domestic air travel moves over time — unlike CPI/WPI.

APIx is a transparent price index over a fixed basket of 12 metro routes, computed with the same Laspeyres methodology used for national price indices.

Slide 1

The Pipeline

1 · Scrape
Playwright + Google Flights, 12 routes × 3 windows (T+1, T+7, T+30), rate-limited to 60 req/hour with retries. → raw_flights
2 · Clean
Dedup, null-fare handling, IQR (1.5×) outlier flagging, per-row quality score. → cleaned_flights
3 · Index
36-cell basket (12 routes × 3 windows), one shared base day = 100, single composite headline, daily/weekly/monthly. → index tables
4 · Serve
One SQLite database (data/apix.db); dashboard + optional FastAPI layer.
Slide 2

The Index Math

APIx(t) = Σ [ Pcell(t) / Pcell(0) × wroute × wwindow ] × 100
  • 36-cell basket — each route × lead window (T+1 / T+7 / T+30) is one cell. One shared base day anchors every cell, so the horizons are directly comparable (no more one-base-per-window).
  • Pcell(t) — the median fare on that (route, window, day); outliers excluded, missing fares carried forward from the last good value so coverage gaps don't fake-crash the index.
  • Pcell(0) — that cell's fare on the shared base day; a cell absent on the base day joins at 100 on its own first day.
  • wcell = route weight × window weight (booking lead-time share, e.g. 20 / 30 / 50 % for T+1 / T+7 / T+30) — both from config/indexer.yaml.
  • The composite blends all cells present that day into one headline per date — a single "book now?" number instead of three confusing lines. Estimator is config-driven: weighted_mean / weighted_trimmed_mean / weighted_median.
  • Weekly = 7-day roll, monthly = 30-day roll; the rolling blend (mean / trimmed_mean / median) is also config-driven.
  • Which estimator is calmest is measured head-to-head by python -m src.indexer.report — average day move, volatility, worst single jump, extreme-day count.
