1. Problem & Goals

India's domestic airfare market has no objective, published price index. APIx fixes that with a transparent, reproducible index over a fixed basket of 12 metro routes — analogous to the government's CPI/WPI baskets.

  • Scrape live fares for 12 directional routes at 3 booking windows (T+1, T+7, T+30).
  • Clean into a trustworthy dataset (dedup, null-handling, IQR outliers, quality score).
  • Index as a Laspeyres weighted basket: base day = 100, published daily / weekly / monthly.
  • Serve from a single SQLite database (data/apix.db) for a dashboard/frontend.

2. Tech Stack

Python 3.11+ · Playwright · pandas · numpy · Pydantic v2 · PyYAML · SQLite · APScheduler · Streamlit · Plotly · pytest

6. The APIx Math

APIxt = Σ [ Pi(t) / Pi(0) × wi ] × 100
  • Pi(t) — lowest fare on the day, per route, per lead window (outliers excluded).
  • Pi(0) — lowest fare on the first day with data for that window.
  • wi — DGCA traffic-share weight, sum ≈ 1.0 (12 routes, from indexer.yaml).
  • Base day index = 100 for every route and every window.
  • Routes missing on a day are omitted; their weight is not re-distributed.

Current weight basket (indexer.yaml, 12 routes)

DEL-BLR0.09BLR-DEL0.09

Sum = 1.00. A fare jump on DEL-BOM (10% of traffic) moves the index 10× more than the same jump on DEL-MAA (6%).
