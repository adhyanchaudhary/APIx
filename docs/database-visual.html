How the Index is Calculated

Step 1: For each route, find the lowest fare today:

SELECT route, MIN(total_fare) AS route_price FROM cleaned_flights WHERE scrape_date = '2026-09-04' GROUP BY route;

Step 2: Calculate route index (base day = 100):

route_index = (today_price / base_price) × 100 Example: DEL-BOM Base price (day 1): ₹12,442 → route_index = 100.00 Today's price: ₹12,882 → route_index = 103.54 (12882 / 12442) × 100 = 103.54

Step 3: Calculate aggregate index (weighted average):

aggregate_index = Σ (route_index × weight) / Σ weight Example with 4 routes: DEL-BOM: route_index=103.54, weight=0.30 → 31.06 DEL-BLR: route_index=98.20, weight=0.20 → 19.64 BOM-BLR: route_index=101.80, weight=0.25 → 25.45 BOM-MAA: route_index=99.50, weight=0.15 → 14.93 ──────────────────────────────────────────────────── aggregate_index = (31.06 + 19.64 + 25.45 + 14.93) / (0.30+0.20+0.25+0.15) = 91.08 / 0.90 = 101.20
Route Weights — From DGCA Passenger Traffic Data

These weights represent what % of India's air traffic each route carries:

DEL ↔ BOM
30% — Heaviest route
BOM ↔ BLR
25%
DEL ↔ BLR
20%
DEL ↔ MAA
10%
BOM ↔ MAA
10%
BLR ↔ MAA
5%
Why weights matter: A price jump on DEL-BOM (30%) affects the index 6× more than the same jump on BLR-MAA (5%). This mirrors real economic impact — more passengers = more consumer spending affected.

Summary

  • 5 tables, all in one SQLite file: data/apix.db
  • raw_flights — Scraper dumps everything here (238 rows now)
  • cleaned_flights — After dedup + outlier detection (75 rows now)
  • daily_index — The actual APIx index number, per route, per day
  • weekly_index / monthly_index — Aggregated versions
  • Index formula: (today_price / base_price) × 100, weighted by traffic share
  • Index = 100 on the first day of data. Above 100 = prices went up. Below = prices went down.
