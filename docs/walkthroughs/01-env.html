PLAYWRIGHT_BROWSERS_PATH=0
Installation choice. A value of 0 tells Playwright to keep browser files inside the project (the virtual environment), rather than a shared global cache. This keeps the project self-contained.

MAX_REQUESTS_PER_HOUR=60
Hard cap: at most 60 requests per hour to Google Flights (about one per minute) so we never hammer the site.
Line 9
REQUEST_DELAY_MIN=3
Minimum wait of 3 seconds between requests.
Line 10
REQUEST_DELAY_MAX=8
Maximum wait of 8 seconds. The scraper picks a random value in this [3, 8] range each time so traffic looks human.
Line 11
MAX_RETRIES=3
If a request fails, retry up to 3 times before giving up on that route x window.
