Comment: what happens when requests fail.
Line 10
max_retries: 3
If a page fails to load, try up to 3 times before giving up.
Line 11
backoff_multiplier: 2 # 3s, 6s, 12s
Each retry waits twice as long as the previous one. 1st retry: 3s. 2nd: 6s. 3rd: 12s. This is called 'exponential backoff.'

Empty line.

# Browser settings
Comment: how the invisible browser should behave.
Line 14
headless: true
Run the browser without a visible window. The browser runs in the background. Set to false to watch the scraper work (useful for debugging).
Line 15
viewport_width: 1280
Browser window width in pixels. 1280 is a standard desktop width.
Line 16
viewport_height: 900
Browser window height in pixels. Together with width, this simulates a typical monitor.
Line 17
user_agent: "Mozilla/5.0 ..."
The browser identifies itself to websites using a 'user agent' string. This one mimics Chrome on Windows. Some websites block requests that don't look like real browsers.
