You type: python src/test_scraper.py

This is the entry point. Everything starts here.

▼

Step 1: Initialize Database

Create the SQLite file and all 5 tables if they don't exist.

database.py → init_db()
  • Creates data/apix.db file
  • Creates tables: raw_flights, cleaned_flights, daily/weekly/monthly_index
▼

Step 2: Load Scraper Config

Read settings from YAML files.

driver.py → load_scraper_config()
  • Reads config/scraper.yaml
  • Gets: headless, viewport size, user agent, timeouts, rate limits
▼

Step 3: Create GoogleFlightsScraper

Instantiate the scraper object with config settings.

google_flights.py → GoogleFlightsScraper()
  • Stores rate limit settings (60 req/hour, 3-8s delay)
  • Stores retry settings (3 retries, 2x backoff)
▼

Step 4: Call fetch_flights()

Request flights for one route: DEL → BOM, 7 days ahead.

google_flights.py → fetch_flights("DEL", "BOM", travel_date, 7)
▼

Rate Limit Check

Have we made 60+ requests this hour? If yes, wait 60 seconds.

google_flights.py → _respect_rate_limit()
▼
Retry Loop (up to 3 attempts)

Step 5: Open Chromium Browser

Launch a visible browser window via Playwright.

driver.py → create_browser_context()
  • Starts Playwright engine
  • Launches Chromium (headless=false → you see the window)
  • Creates Incognito-like context (1280×900, custom user agent)
  • Sets 30-second timeout
▼

Step 6: Build Google Flights URL

Construct the search URL from route and date.

google_flights.py → _build_url()
  • Input: origin="DEL", dest="BOM", date=2026-09-11
  • Looks up city names: DEL → "New Delhi", BOM → "Mumbai"
  • Builds: google.com/travel/flights?q=Flights from New Delhi to Mumbai on 2026-09-11
▼

Step 7: Navigate to Google Flights

Browser loads the page. This is where you see the window open and navigate.

google_flights.py → page.goto(url)
  • Browser waits for page to load (DOM ready)
  • Google Flights runs JavaScript to fetch flight data
▼

Step 8: Wait for Flight Cards to Appear

Try multiple CSS selectors until flight results load.

google_flights.py → _wait_for_results()
  • Tries: li.pIav2d → div[role=link] → li[class*=pIav2d] → ul[role=list] > li
  • Each selector waits up to 15 seconds
  • If none match → logs warning, continues anyway
▼

Step 9: Collect aria-labels from Flight Cards

Run JavaScript in the browser to extract all aria-label text.

google_flights.py → _collect_aria_labels()
  • Runs JS via page.evaluate() — directly in the browser
  • Finds all elements with aria-label attribute
  • Filters: keeps only labels containing "rupees" AND "flight"
  • Returns array of strings like: "Nonstop flight with IndiGo. Leaves New Delhi at 8:45 AM. Arrives Mumbai at 11:00 AM. Total duration 2 hr 15 min. From 12882 Indian rupees."
▼
For Each aria-label (100-120 labels)

Step 10: Parse the aria-label string

Extract structured data from the plain English text using regex.

google_flights.py → _parse_aria_label()
▼

Extract Price

_extract_price_from_label() — Regex: "From 12882 Indian rupees" → 12882

Extract Carrier

_extract_carrier_from_label() — Regex: "with IndiGo" → "IndiGo"

Extract Stops

_extract_stops_from_label() — Checks: "nonstop" → 0, "1 stop" → 1

Extract Times

_extract_time_from_label() — Regex finds "at 8:45 AM" and "at 11:00 AM" → departure and arrival

Extract Duration

_extract_duration_from_label() — Regex: "2 hr 15 min" → 135 minutes

▼

Valid Flight?

Must have: price, carrier, departure time, and (arrival time OR duration).

  • Missing price or carrier → skip
  • Missing departure time → skip
  • Missing both arrival time AND duration → skip
▼

Create FlightRecord Object

Package all extracted data into a Pydantic model.

schemas.py → FlightRecord(...)
  • Computes arrival time: if arrival parsed, use it; else departure + duration
  • Fixes next-day: if arrival < departure → adds 1 day
  • Timestamps the record with current time
▼

Step 11: Return List of FlightRecords

All valid flights from this page are returned as a list. (Typically 100-120 records)

google_flights.py → return records
▼

Step 12: Insert into Database

Write all FlightRecords to the raw_flights table in SQLite.

run_scrape.py → _insert_records()
  • Opens connection to data/apix.db
  • Converts each FlightRecord to a tuple of 16 values
  • Batch inserts with executemany() — one SQL query for all rows
  • Commits (saves) to disk
▼

Step 13: Close Browser

The finally block runs automatically — closes tabs, then kills Chromium.

driver.py → context.close() → browser.close()
▼

More routes × windows to scrape?

12 routes × 3 windows = 36 combinations. If more remain, go back to Step 4.

  • Route loop: DEL→BOM, DEL→BLR, DEL→MAA, BOM→DEL, BOM→BLR, ...
  • Window loop: T+1, T+7, T+30 for each route
▼

Done! All flights saved to raw_flights.

120 rows in the database. Ready for cleaning (Phase 2).

How data transforms along the way

1. Raw aria-label from Google Flights (plain English string)
"Nonstop flight with IndiGo. Leaves New Delhi at 8:45 AM. Arrives Mumbai at 11:00 AM. Total duration 2 hr 15 min. From 12882 Indian rupees."
↓ regex extraction ↓
2. Extracted fields (Python dictionary)
{ price: 12882, carrier: "IndiGo", stops: 0, dep: "8:45 AM", arr: "11:00 AM", duration: 135 }
↓ FlightRecord model ↓
3. FlightRecord object (typed, validated)
FlightRecord(route="DEL-BOM", origin="DEL", dest="BOM", carrier="IndiGo", depart_time=datetime(2026,9,11,8,45), arrive_time=datetime(2026,9,11,11,0), duration_mins=135, stops=0, total_fare=12882.0, ...)
↓ SQL INSERT ↓
4. Row in raw_flights table (SQLite)
| id=1 | scrape_date=2026-09-04 | route=DEL-BOM | carrier=IndiGo | | dep=2026-09-11 08:45 | arr=2026-09-11 11:00 | dur=135 | stops=0 | | fare=12882.0 | currency=INR | window=7 | scraped=2026-09-04 15:30:00 |
One command → browser opens → visits Google Flights → reads 120 aria-labels → regex extracts price/times/carrier → packages into FlightRecords → saves to SQLite → browser closes. 13 steps, ~15 seconds, 120 flights scraped.
