0 Problem Summary

India's CPI airfare data is collected manually from limited ticketing outlets. With 90%+ of domestic air tickets sold online via OTAs and dynamic pricing (fares vary 200–400% in a day), the CPI airfare component is no longer representative of what Indian consumers actually pay.

Goal: Build an automated scraping + cleaning + indexing pipeline that produces a Real-time Airfare Price Index (APIx) for daily, weekly, and monthly consumption by NSO and RBI.
MVP uses Google Flights only. Airline + OTA multi-source scraping is Phase 2. Start small, prove validity.

5 APIx Index Calculation

Formula (Laspeyres-style):

APIx(t) = Σi=1..n [ Pi(t) / Pi(0) × wi ] × 100

Where:
  • Pi(t) = lowest fare on route i at time t
  • Pi(0) = lowest fare on route i at base day (Day 1 = 100)
  • wi = DGCA traffic-share weight for route i (∑wi = 1)

Example with 4 routes and weights:

RouteWeight (wi)Day 0 PriceDay 5 PriceRatioContribution
DEL→BOM0.30₹4,500₹5,2001.15634.67
DEL→BLR0.25₹5,100₹5,8001.13728.43
BOM→BLR0.25₹3,800₹4,1001.07926.97
DEL→MAA0.20₹6,200₹6,5001.04820.97
APIx(Day 5) = (34.67 + 28.43 + 26.97 + 20.97) = 111.04 → 11% increase in 5 days
